# Presentation Materials

This folder contains all presentation materials for the SWE363 Assignment 4 final project demonstration.

| File | Description |
|------|-------------|

## Video Presentation Requirements

**Duration:** 5-7 minutes
**Format:** MP4 (recommended)

### Presentation Structure

| Section | Duration | Content |
|---------|----------|---------|
| Introduction | ~1 min | Project overview, objectives, personal motivation |
| Technical Demo | ~3 min | Live demonstration of all key features |
| Technical Deep Dive | ~2 min | Challenges, solutions, lessons learned |
| Conclusion | ~1 min | Outcomes, future improvements, closing |

## Recording Setup

### Recommended Tools
- **OBS Studio** (free, cross-platform) - Professional quality
- **Windows Game Bar** (Win + G) - Quick and easy
- **Loom** - Simple with webcam overlay

### Recording Checklist

Before recording:
- [ ] Close unnecessary applications
- [ ] Disable notifications
- [ ] Test microphone audio levels
- [ ] Have website open and ready
- [ ] Clear browser history/tabs for clean demo
- [ ] Test all features work correctly

### Video Settings
- **Resolution:** 1920x1080 (1080p) recommended
- **Frame Rate:** 30 fps
- **Audio:** Clear microphone, minimal background noise
- **Webcam:** Optional small overlay in corner

## Presentation Tips

1. **Practice** - Run through 2-3 times before final recording
2. **Pace** - Speak clearly and not too fast
3. **Energy** - Be enthusiastic about your work
4. **Focus** - Highlight what makes your project unique
5. **Time** - Stay within the 5-7 minute limit
6. **Demo the Easter Egg** - The Konami code is impressive!

## Troubleshooting

| Issue | Solution |
|-------|----------|
| GitHub API not loading | Check internet connection, use retry button |
| Theme not persisting | Clear localStorage and test again |
| Animations not working | Refresh page, check console for errors |
| Mobile menu not working | Test in actual mobile or dev tools |
